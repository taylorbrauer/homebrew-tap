# Taylor Brauer's Homebrew Tap

## Touchy — Touch Screen & Logo Toggle

```
brew tap taylorbrauer/tap
brew install --cask touchy
```

Website: https://touchymac.com

To uninstall (also stops Touchy's helper):

```
brew uninstall --cask --zap touchy
```

`Casks/touchy.rb` is updated automatically by Touchy's release workflow.
